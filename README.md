# Tableau Data Visualization Portfolio (TuteDude Certification)

This repository contains a series of Tableau projects completed as part of the TuteDude Tableau Certification course. The projects range from foundational data connections and basic charts to advanced storytelling and interactive business dashboards.

## 📌 Project Overview
The portfolio is divided into four main assignments, each focusing on specific Tableau functionalities:
1. **Sales & Performance Analysis** (Bar Charts & Time Series)
2. **Geographic & Relationship Analysis** (Maps, Joins & Dashboards)
3. **Advanced Analytics** (Calculations, Histograms & Storytelling)
4. **Capstone Project** (Real-world Data Dashboard)

---

## 📊 Project 1: Category Performance & Trends
**Objective:** Analyze sales performance across categories and identify seasonal trends.

* **Tasks:** * Connected Tableau to CSV/Excel data sources.
    * Developed a **Bar Chart** to compare Sales/Profit across different Categories.
    * Developed a **Time Series (Line Chart)** to visualize growth trends over time.
    * Implemented Global Filters (Region, Category) for interactivity.
* **Key Learnings:** Data connection, dimensions vs. measures, and basic filtering.

---

## 🗺️ Project 2: Geographic Insights & Integrated Dashboards
**Objective:** Work with multiple data sources and geographic visualizations to build the first interactive dashboard.

* **Tasks:** * Performed **Data Joining** (Inner/Left Joins) to combine disparate datasets.
    * Created a **Geographic Map** visualizing performance by State/Region.
    * Created a **Scatterplot** to analyze the correlation between two numerical variables (e.g., Profit vs. Sales).
    * **Dashboarding:** Combined the map and scatterplot into an interactive dashboard.
    * **Actions:** Added Filter and Highlight actions for a seamless user experience.
* **Key Learnings:** Data modeling, spatial analysis, and dashboard action triggers.

---

## 📈 Project 3: Advanced Calculations & Storytelling
**Objective:** Use deep-dive analytics and Tableau "Stories" to present data-driven narratives.

* **Tasks:** * **Calculated Fields:** Implemented Running Totals, Percent Differences, and Ranks.
    * **Distribution:** Used Bins to create a **Histogram** for data frequency analysis.
    * **Tree Map:** Developed a Tree Map to show hierarchical part-to-whole relationships.
    * **Tableau Story:** Compiled findings into a 3-point Story with captions and narrative flow.
* **Key Learnings:** Table calculations, data binning, and presentation of insights.
